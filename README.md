# Capstone_1

This project uses MySQL and Excel to analyze sales performance for EmporiUm, a fictional student bookstore chain that sells books, technology, art supplies, and other products in stores and online.

The analysis focuses on **Ohio online sales**. It examines total revenue, monthly sales trends, territory performance compared with its region, transaction patterns, and sales rankings. The findings will support a recommendation for where to focus sales attention next quarter.

SQL queries will be used to analyze the sample_sales database, and an Excel PivotChart will visualize selected results.
