# Capstone_1

EmporiUm is a fictional student bookstore chain. The terorrity/state that this analysis will go over is Ohio.

The tools used for this analysis were the following:
- MySQL Workbench
- Git
- Git Hub
- Excel

Key findings from the analyses:
- Ohio only had online sales, it didn't have any in-store locations
- Overall sales: 1,408 recorded transactions generated $992,242.72, covering January 2, 2022–October 20, 2025.
- Technology & Accessories dominates: It generated $714,885.07—72% of Ohio revenue across 361 transactions, averaging $1,980.29 per transaction. It had both the highest revenue and the largest full-period transaction count.
- Textbooks is the second-largest contributor: It generated $186,002.94.
- All together, Technology & Accessories and Textbooks accounted for 90.8% of revenue.
  
Business Rec:
- Focusing sales attention towards Technology & Accessories as it is consistently producing the largest number of online sales for the state.
